# 📚 考研复习桌面浮窗计划工具

一个常驻桌面的考研复习小工具：置顶浮窗展示**每日计划 / 专注计时 / 定时提醒**，界面跟随 Windows 深浅色自动切换，关闭浮窗后变成**桌面宠物「艾莲」**（对话气泡、AI 闲聊、可发图识别、还能帮你在对话里改计划），提醒不中断。

## 功能
- **今日计划**：输入添加每日任务，勾选完成自动划去并显示「已完成 X/Y」进度；支持编辑、右键操作、删除确认和一键清理已完成；跨天自动归档昨日计划。
- **专注计时（正计时）**：按下「开始」后从 0 向上累计时间，计时过程可暂停/继续/重置；专注分钟数自动按小时写入统计。可设置每隔 N 分钟（默认 60）提醒喝口水、活动一下——提醒时**计时不停**。
- **专注统计（直方图）**：「专注统计」页签按小时画出当天专注分布直方图（X 轴 0-23 点，Y 轴专注分钟数），可 ◀/▶ 翻看历史各天，并显示总量、活跃时段与高峰时段。
- **提醒**：按「时:分」添加定时提醒，自动按时间排序并提示下一次提醒；可单独开关/删除，到点弹窗 + 系统通知。
- **未完成任务提醒**：每 N 分钟检查当天待办，有未完成则在右下角系统通知 + 浮窗 + 提示音提醒（可关、间隔可调，启动后约 8 秒先提醒一次方便确认生效）。
- **考研倒计时**：设置考研日期后，浮窗头部实时显示「距考研还有 X 天」。
- **桌面宠物「艾莲」**：点「×」后主浮窗收起为桌宠（使用 `desk_pet/*.ani` 动画：常态 normal / 对话·思考·回答 talking_1 / 被夸 happy / 点赞 present / 太久没互动趴睡 sleep）。单击仅用于拖动，**右键**出菜单（回到主窗口 / 设置 / 打开聊天记录 / 退出）；头顶常驻淡蓝状态条实时显示**任务进度 + 专注正计时**；下方常驻圆角输入框可直接对话；偶尔会蹦出加油/闲话气泡。
- **宠物对话**：桌宠下方常驻输入框，回车发送，宠物用气泡回复（右键菜单可打开完整聊天记录窗）。可在对话里直接**改计划**（如「添加 背单词」「划掉 背单词」「删除 背单词」「列出计划」「全部完成」），也能**遥控专注计时**（「开始专注」「暂停专注」「继续专注」「结束专注」会真正启停浮窗里的正计时）；普通聊天走免费 AI **智谱 GLM-4.6V-Flash**（已配 Key，**支持图像识别**——在聊天框 Ctrl+V 粘贴图片即可发图给艾莲）；主模型限流（429/403）时自动降级到 `glm-4-flash`/`glm-4v-flash`，全不可用才用本地回复，改计划照常可用。
- **实时媒体字幕（黑板）**：右键桌宠勾选「启用字幕」后，桌宠旁出现一块**独立黑板**，实时把电脑播放的声音（视频/网课/音乐）转成字幕滚动显示（识别**系统播放声音**，不是麦克风）。与对话气泡完全独立互不影响；黑板可拖动、**四边四角自由缩放（字号保持设置值不变）**、单击清空，字幕带时间戳、可滚动保留最近 6 条；半成品字幕尾部带**闪烁打字光标**，字幕生成时**艾莲进入“说话”表情**（停止约 1.6 秒后回常态，纯 UI 动画不影响识别速度）；切分使用**自适应静音门限**（声音偏小的视频也能识别）；**流式预览**——说话过程中每 1.5 秒出一版“半成品”字幕实时替换，整句说完再定稿；识别与切分并行、队列设上限防积压、相同句子自动去重（不重复刷屏），内存实时释放；「字幕设置…」可配识别 Key、识别模型、语言（自动/中/英/粤/日/韩）、字号、粉笔颜色。识别用**硅基流动**（免费无用量限制）：默认 **SenseVoiceSmall**（低延迟、实时友好、中文准、自带标点，支持中/英/日/韩/粤），可切 **TeleSpeechASR**（中文高精度、方言/口音/嘈杂音频更强，但推理慢）。Key 写在本地 `secret.json`（已 gitignore，不入仓库）。
- **语音输入 🎤**：右键桌宠勾选「语音输入」开启后，聊天栏右侧出现**按住说话的麦克风按钮**——按住说话、松开自动识别（走系统默认麦克风，复用硅基流动 ASR，与字幕黑板完全独立）。识别出的文字自动填进聊天框并发出：可以直接说「添加 背单词」「划掉 数学卷子」等指令语音改计划，也能直接跟艾莲聊天。随时可右键再勾掉关闭。
- **语音播报 🔊（艾莲开口说话）**：右键桌宠勾选「语音播报」，艾莲的**聊天回复和闲话会用她的声音念出来**。声音来自你本机的 GPT-SoVITS 推理服务（默认 `http://127.0.0.1:9880`，POST /tts 返回 WAV）——配好服务后，右键「语音播报设置…」填**服务启动命令**和**参考音频路径**（音色来源，艾莲的声音就靠它），宠物会在你开启开关时自动拉起服务、关闭时终止它。**关闭开关即零占用**：不占线程、不占性能、模型显存一并释放；服务没起或没配参考音频时艾莲照常气泡回复、不崩溃。详见下方「给艾莲配音」。
- **浮窗交互**：无边框置顶、拖动标题栏移动、折叠为迷你条、托盘可显示/隐藏或退出。
- **主题**：跟随 Windows 深浅色模式，3 秒内自动切换。

## 安装运行
```bash
# 进入项目目录
cd C:\Users\21495\kaoyan_planner

# 安装依赖（PyQt5、plyer）
pip install -r requirements.txt

# 运行

```

> 提示：开机自启可在「运行」(Win+R) 输入 `shell:startup`，把 `main.py` 的快捷方式放进去即可。

## 使用说明
1. **添加计划**：切到「今日计划」页，输入内容回车或点「添加」；勾选方框即完成划去，点任务右侧 ✎ 编辑、✕ 删除，也可右键任务操作；底部可清理已完成任务。
2. **专注计时**：点「开始」进入正计时，时间从 0 向上累计；点「暂停/继续」保留进度，点「重置」清零。可勾选「定时提醒喝水休息」并设置间隔（默认每 60 分钟），到时右下角提醒、计时不停。下方显示今日专注统计，点「专注统计 ▸」跳到直方图页。
3. **专注统计**：切到「专注统计」页，直方图展示选中日期 0-23 点每小时专注分钟数；用 ◀/▶ 翻看历史日期，顶部提示总量、活跃时段和高峰时段。
4. **添加提醒**：切到「提醒」页，选时间、填内容、点「添加」；点「开/关」按钮可单独启停，✕ 删除。「未完成任务提醒」开关和间隔也在本页底部。
5. **设置考研日期**：点浮窗上「⚙ 设置」，选择日期点确定，头部即显示倒计时。「桌宠 AI 对话」栏目可改 API 地址 / 模型 / Key（已预配智谱 **GLM-4.6V-Flash**，支持图像识别）。
6. **桌面宠物「艾莲」**：点浮窗右上角「×」收起为桌宠。**单击仅用于拖动**，右键→菜单（回到主窗口 / 设置 / 打开聊天记录 / 退出）。头顶淡蓝状态条实时显示「已完成 X/Y · 专注/未专注」（专注中显示本次正计时）。桌宠会用 `.ani` 动画表达状态：常态播放 **normal**，点击输入框对话、等待回复（思考）和气泡回答时播放 **talking_1**，**识别到你夸它**（如"好棒/可爱/聪明/厉害/乖/喜欢你"）时播放 **happy**，待办完成（如聊天里说「划掉 XXX」）时播放「点赞」**present**；**超过 5 分钟没人互动会自动「趴睡」播放 alternate**，点一下宠物、拖动或说话都会把它叫醒。
7. **宠物聊天改计划**：桌宠下方常驻圆角输入框，输入指令回车，例如「添加 背单词」「划掉 背单词」「删除 背单词」「列出计划」「全部完成」；宠物用气泡回复。也可直接**遥控专注计时**：「开始专注 / 开始计时 / 开始番茄 / 专注一下」启动正计时，「暂停专注 / 暂停计时 / 暂停」暂停，「继续专注 / 继续计时 / 继续」续上，「结束专注 / 停止专注 / 重置计时」清零结束，回复会回显已专注分钟数。普通聊天走免费 AI 艾莲；**在输入框 Ctrl+V 粘贴图片可直接发图给艾莲识别**。完整聊天记录可右键宠物 →「打开聊天记录」。
8. **折叠/退出**：点头部「—」折叠为迷你条（点一下展开）；托盘右键可「显示/隐藏 浮窗」或「退出」关闭程序。
9. **实时媒体字幕**：右键桌宠 → 勾选「启用字幕」，桌宠旁出现黑板，实时显示电脑播放声音的字幕；右键 →「字幕设置…」先填入硅基流动识别 Key（[cloud.siliconflow.cn](https://cloud.siliconflow.cn) 免费申请，无用量限制，无需绑卡），再选语言/字号/颜色。黑板可按住拖动、拖四边四角自由缩放（字号不变）、单击清空。关闭字幕只需再取消勾选。首次使用会提示「未配置 ASR Key」。注意：媒体声音会**上传云端识别**，有隐私考量（如在意可改用本地 FunASR，架构已预留）。

## 给艾莲配音（语音播报，可选）

艾莲的“声音”来自本机跑的 **GPT-SoVITS** 社区音色模型（社区已有人炼好《绝区零》艾莲·乔的模型，免费）。配好后右键桌宠勾选「语音播报」，她回复、闲话就会念出来。

1. **装推理服务**（推荐 GSVI，GPT-SoVITS 的推理简化版）：
   `git clone https://github.com/AI-Hobbyist/GPT-SoVITS-Inference` 到你想要的位置（如 `C:\Users\21495\gsvi`），在 Anaconda 里 `pip install -r requirements.txt`（本机已装 PyTorch+CUDA）。
2. **下艾莲的模型**（任选其一，模型文件 = GPT 权重 `.ckpt`/`.pth` + SoVITS 权重 `.pth` + 参考语音 `.wav`）：
   - 在 GSVI 的 WebUI（`gsvi.bat`）社区模型库里搜「艾莲/Ellen」一键下载到 `models/`；
   - 或 B站「白菜工厂1145号员工」《绝区零全角色GPT-SoVITS模型》免费合集，度盘 `pan.baidu.com/s/1x_THJNAZU-aExdAKfCUdbg?pwd=1145`（123盘 `www.123pan.com/s/UHp9-kqi8H.html`），解压找艾莲的文件放 `models/v2/`。
3. **指给模型加载配置**：编辑 `GPT_SoVITS/configs/tts_infer.yaml` 的 `custom:` 段，把 `t2s_weights_path`/`vits_weights_path` 指向艾莲的权重，`device: cuda`、`is_half: true`。
4. **填启动命令 + 参考音频**：右键桌宠 →「语音播报设置…」，填：
   - **服务启动命令**：例如 `cmd /c "cd /d C:\Users\21495\gsvi && C:\Users\21495\gsvi_venv\Scripts\python.exe api_v2.py -p 9880"`；
   - **参考音频路径**：艾莲的一句话录音（`ref.wav`，音色就来自它，模型包里通常自带）；
   - **参考音频文字**：这段录音里说的话（转写，填了音色更稳）。
5. **开启**：右键桌宠勾选「语音播报」。宠物会自动拉起服务、等服务就绪后才开口；**取消勾选或退出程序时，宠物会终止服务进程，模型不再占用显存和线程（零占用）**。若没填启动命令（服务由你手动启动），宠物只负责发文字。

性能参考（本机实测，RTX 4060 Laptop + 基础 v2 模型）：模型加载约 **16 秒**；开启后占用 **显存约 2.1 GB、内存约 2.5 GB、空闲 CPU ≈ 0%**（只挂着等请求）；合成一句 6~7 秒的话约 **2.4 秒**（RTF≈0.4，约 2.5 倍实时，合成瞬间 CPU 峰值短暂到 ~900% 后回落），**首次合成**含 onnxruntime 暖机会慢到 7~8 秒。换成 v2ProPlus 或社区更快的模型会明显更快。想实测本机占用可运行 `python bench_tts.py --cmd "…启动命令…" --ref 参考音频.wav --prompt "转写文字"`（连模型加载耗时一起测）。

## 数据文件
- `data.json`：计划、提醒、设置等数据，修改时自动保存，重启不丢失。
- 专注统计保存在 `data.json` 的 `focus_history`（按「天 → 小时」的专注分钟数）中，正计时过程中约每 15 秒自动写入；旧版 `focus_sessions` 记录会在启动时自动迁移进直方图。
- 数据损坏时程序会自动备份为 `data.json.bak` 并重建默认数据。
